# Fuentes embebidas en `tema.css`

- **Inter** (pesos 400 y 600), de Rasmus Andersson.
- **JetBrains Mono** (pesos 400 y 700), de JetBrains.

Ambas se distribuyen con la [SIL Open Font License 1.1](https://openfontlicense.org),
que permite incrustarlas y redistribuirlas. Solo se incluye el alfabeto latino.

Se regeneran con `uv run python scripts/presentaciones/tema.py fuentes` (necesita internet
una vez; después las diapositivas funcionan sin conexión).
